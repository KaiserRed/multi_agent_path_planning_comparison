\abstract % Структурный элемент: РЕФЕРАТ

\keywords{МУЛЬТИ-РОБОТИЗИРОВАННЫЕ СИСТЕМЫ, MAPF, MRTA, ПОИСК БЕСКОНФЛИКТНЫХ МАРШРУТОВ, РАСПРЕДЕЛЕНИЕ ЗАДАЧ, CBS, PIBT, СРАВНИТЕЛЬНЫЙ АНАЛИЗ АЛГОРИТМОВ, ПРОГРАММНЫЙ КОМПЛЕКС}

Объектом разработки является кроссплатформенный программный комплекс для оценки эффективности алгоритмов управления мульти-роботизированными системами.

Цель работы~--- создание программного комплекса, позволяющего проводить тестирование и сравнительный анализ алгоритмов поиска бесконфликтных маршрутов (MAPF) и распределения задач (MRTA) в мульти-роботизированных системах при различных конфигурациях среды.

Методы проведения работы: анализ и классификация существующих алгоритмов MAPF и MRTA на основе научной литературы; объектно-ориентированное проектирование с применением паттерна <<Стратегия>> для обеспечения модульности и расширяемости; реализация алгоритмов на языке Python с использованием библиотеки Pygame для графического интерфейса; автоматизированное пакетное тестирование с варьированием параметров среды и статистической обработкой результатов.

В ходе работы реализованы восемь MAPF-алгоритмов (CBS, CBS-SIPP, ECBS, EECBS, M*, CA*, WHCA*, PIBT) и пять MRTA-алгоритмов (венгерский, жадный, последовательный аукцион, минимальная стоимость потока, комбинаторный аукцион). Разработан графический интерфейс, включающий редактор сеточных карт, визуализацию симуляции в реальном времени и режим пакетного тестирования с автоматической генерацией графиков. С помощью PyInstaller обеспечена сборка в автономный исполняемый файл для Windows, Linux и macOS.

Новизна результатов состоит в объединении тринадцати алгоритмов двух классов задач управления МРС в единой программной среде с интерактивной визуализацией и автоматизированным сравнительным анализом, что ранее не было представлено в доступных инструментах.

Область применения: образовательный процесс в области робототехники и искусственного интеллекта, исследовательская деятельность при выборе алгоритмов для конкретных прикладных задач координации групп роботов, а также прототипирование систем управления складской логистикой, автономным транспортом и поисково-спасательными операциями.

Значимость работы определяется предоставлением единого инструмента для обоснованного выбора алгоритмов управления мульти-роботизированными системами на основе объективных метрик эффективности в контролируемых условиях.
